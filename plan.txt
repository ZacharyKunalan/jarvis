🧭 3. Decision Logic (VERY IMPORTANT)

When text is received:

Step 1: Check if timetable-related

Trigger words like:

“schedule”
“timetable”
“next”
“today”
“tomorrow”
specific days (“Monday” etc.)

👉 If YES:
→ handle with timetable system

👉 If NO:
→ send to AI (ChatGPT)

Step 2: If unclear
Ask follow-up:
“Do you mean your schedule?”
Step 3: Fallback
If nothing matches → treat as general AI question
📅 4. Timetable Behavior
Queries it should handle:
“What do I have today?”
Get current day
Return all events for that day
“What’s next?”
Get current time
Find next upcoming event today
If none:
say “You’re done for today”
“What do I have tomorrow?”
Get next day
Return events
“What do I have on [day]?”
Match day
Return events
Response Style
Clear + natural:
“You have Math at 9am and Physics at 11am”
🔁 5. Conversation Behavior (Simple Memory)
Remember last question context briefly

Example:

You: “What do I have tomorrow?”
Then: “What about Friday?”

👉 It understands you're still talking about timetable

⚠️ 6. Error Handling
If speech unclear:
“I didn’t catch that, can you repeat?”
If no timetable data:
“You don’t have anything scheduled”
If unknown command:
fallback to AI

def handle_input(text):
    if is_timetable_query(text):
        return handle_timetable(text)

        return ask_ai(text)


def run_jarvis():
    while True:
        if listen_for_wake_word():
            audio = record_audio()
            text = speech_to_text(audio)

            response = handle_input(text)

            speak(response)
